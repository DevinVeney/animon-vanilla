# Animon

A six-page anime and manga catalogue site written in plain HTML and CSS — no framework,
no build step, no JavaScript dependencies.

```
index.html     landing
anime.html     anime listings
manga.html     manga listings
links.html     external resources
about.html     about
contact.html   contact form
style.css      single stylesheet, ~800 lines with the markup
```

Open `index.html` directly in a browser, or serve the directory:

```bash
python3 -m http.server
```

## Status

An early project (2024) from before I moved to component frameworks. Kept public as a
record of the hand-written HTML and CSS stage — layout, responsive breakpoints and
typography done without a toolchain.
